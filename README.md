# 바둑돌 미식축구 감독

친구와 브라우저로 하는 미식축구 감독 게임. 둘이 동시에 작전을 고르면 바둑돌 선수들이 스스로 움직여 결과가 나온다.

## 파일
- `data.js` — 팀·선수 능력치(1~99), 공격/수비 작전, 경기 규칙 수치. **수치는 여기서만 고친다.**
- `sim.js` — 한 플레이 시뮬레이션(블로킹·제치기·태클 뿌리치기·펌블·패스·가로채기). 결과를 녹화(프레임+사건)로 돌려준다.
- `rules.js` — 기회(다운)·10야드·점수·공격권 교대·경기 끝·상황 힌트.
- `view.js` — 경기장 그리기·녹화 재생·점수판·작전 카드·팀 능력치 표.
- `main.js` — 방 만들기/참가(PeerJS, 방 코드 4글자), 방장이 계산하고 손님은 작전만 보냄.

## 끊김 대비
- 손님이 끊기면 방장은 작전 시간을 멈추고 기다린다. 손님은 같은 코드로 자동 재접속한다.
- 방장이 새로고침하면 첫 화면의 [이어하기]로 같은 방 코드를 다시 연다 (경기는 방장 브라우저에 저장).

## 실행
- 로컬: `C:\AI\.claude\launch.json` 의 `gridiron` (포트 8793)
- 수치 확인 도구 (node):
  - `node tools/summary.js` — 공격 작전 × 수비 작전 평균 야드·뺏김·터치다운 (카드의 강함/약함 글귀 근거)
  - `node tools/balance.js` — 팀별 자세한 표
  - `node tools/fullgame.js` — 무작위 작전으로 경기 끝까지 (점수·플레이 수·예상 시간)
  - `node tools/trace.js <공격작전> <수비작전> <seed>` — 한 플레이 움직임 추적
